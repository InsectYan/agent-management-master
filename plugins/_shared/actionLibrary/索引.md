# 公共动作知识库

生成提示词的技能整理镜头时，正文或常规稿里出现动作，就读取这里对应的模版，把起始姿态、肢体路径和结束姿态写进提示词。

新增打戏或特效时，在 `packs/` 放一篇说明，再在 `index.js` 的目录里加一条。`group` 用 `fight` 或 `fx`，`gate` 用 `none`。不要改已有亲密模版的使用条件。

## 使用条件

亲密类模版只在这一镜里发生身体接触的人都已写明满二十一岁时调用。没写年龄，或出现未满二十一岁，不调用亲密模版，只保留单人的肢体路径。

打戏和特效没有年龄门槛。这两类现在还没有条目。

## 词语置换

`phraseMap.json` 由人维护。左边是生成结果里要换掉的原句，右边是写进画面的说法，例如「走向床铺」换成「转身朝着床铺方向走去」。

`cartoon-prompt-skill` 和 `cartoon-av-prompt-skill` 在落库前对视频提示词、首帧、尾帧做整句替换，长句优先。「」里的对白原句不替换。负向和音效备注也不替换。表里没有的说法不要另写一条替换。改这份 JSON 后，下一次生成提示词就会读到，不必改技能代码。

男女体征写在 `anatomy.md`。AV 收口要同时满足三步才引用它：项目已勾选 AV，这一镜的描述或对白写了性爱，并且双方都已写明满二十一岁。模版动作写到人物卡里的出场人物身上。常规提示词技能不引用这份体征说明。没有描述性爱的镜头不调用 AV 收口。

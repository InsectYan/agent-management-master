# AI 真人剧 · 经典艺术类风格「公式化」细节填充手册

> 本手册**不是风格的二次描述**，而是严格套用《视觉资产提示词公式手册》定义的**四大公式模块顺序**（服装 / 人物 / 场景 / 人景融合），为 8 种经典艺术类风格**逐槽位**给出「这一格该填什么细节」的取数口径。
>
> 用途：把小说文本喂给大模型后，按本表逐格召回、补全每个槽位的取值，再组装为可执行提示词。每种媒介的识别度全靠"笔触 / 颗粒 / 晕染 / 刀痕 / 剥落感"这一层肌理，因此本册在每个槽位都额外标注了 **「该媒介如何把物理描述翻译成媒介语言」**。

---

## 〇、公式槽位框架（取数骨架）

四大公式的模块顺序（与母手册完全一致，固定不换）：

| 公式 | 槽位顺序（逐格填值） |
| --- | --- |
| **服装** | 颜色 → 材质 → 款式 → 细节设计 → 工艺特征 → 整体风格 → MJ参数 |
| **人物** | 基础身份 → 面部特征 → 身材体型 → 发型妆容 → 服装细节 → 饰品道具 → 光影氛围 → 镜头构图 → 风格质感 → MJ参数 |
| **场景** | 空间类型 → 建筑结构 → 材质纹理 → 光影氛围 → 叙事道具 → 镜头构图 → 天气时间 → 风格质感 → MJ参数 |
| **人景融合** | 景别构图 → 人物锚点 → 动作落脚点 → 空间前后景 → 光影统一 → MJ参数 |

### 经典艺术类·三条共性铁律

1. **媒介即风格**：先定"用什么媒介画"（油画堆塑 / 水彩晕染 / 炭笔排线 / 刻刀凿痕 / 矿物颜料剥落 / 蛋彩罩染 / 色粉推抹），再填内容。同一件衣服，油画写成"厚堆颜料+明暗塑形"，水彩写成"透明叠色+边缘留水痕"，二者槽位结构相同、取值完全不同。
2. **肌理取代皮肤**：写实类讲"毛孔/雀斑"，艺术类则把皮肤改写成**媒介肌理**——油画是"颜料的厚薄与笔触方向"，素描是"排线的疏密"，版画是"黑白两分的刀路"，不存在真实肤质，只存在"媒介如何表现肉感"。
3. **光影为艺术服务，可脱离物理真实**：写实类光影必须可追溯光源；艺术类光影可按构图需要自由夸张（伦勃朗的暗角、印象派的碎光、壁画的平面装饰光），一切服从情绪与画面秩序。

## 一、古典油画（classic-oil）

**媒介内核**：厚堆颜料 + 明暗对照法（Chiaroscuro）+ 单一暖光源；暗部沉入近黑，亮部堆出颜料厚度。

### 服装公式
| 槽位 | 取值口径 |
| --- | --- |
| 颜色 | 深沉暖调为主：绛红、墨绿、赭石、暗金、深褐；亮部暖金、暗部冷褐，整体低明度高密度。 |
| 材质 | 天鹅绒、织锦、重磅绸缎、毛皮——取"厚重、吸光、有分量"的料子；反光以"颜料高光点"表现而非镜面。 |
| 款式 | 古典宫廷剪裁：立领拉夫领、宽袖长袍、束腰长裙、披风斗篷。 |
| 细节设计 | 用厚颜料堆出刺绣凸起、珠链颗粒、褶皱明暗；衣褶作"暗部—转折—高光"三段塑形。 |
| 工艺特征 | 厚涂堆塑（impasto）、罩染叠色、边缘柔和虚化；亮部颜料堆得可见厚度。 |
| 整体风格 | 庄重、内敛、古典主义、博物馆藏品质感。 |
| MJ参数 | `--style raw --stylize 250 --ar 2:3`（肖像竖幅）。 |

### 人物公式
| 槽位 | 取值口径 |
| --- | --- |
| 基础身份 | 贵族、绅士、淑女、神职者、学者；气质取端庄、肃穆、克制。 |
| 面部特征 | 骨相立体、明暗对照塑形：受光半脸清晰、背光半脸融于暗部；肤色温润暖调、由亮到暗连续过渡。 |
| 身材体型 | 端庄挺拔，比例古典理想化；手部骨点用明暗交代。 |
| 发型妆容 | 自然发色、低饱和妆容；发丝以细笔+高光勾出，边缘柔融背景。 |
| 服装细节 | 调用服装公式，强调"颜料厚度"承载的华贵。 |
| 饰品道具 | 珍珠、金饰、书卷、单支烛台；以高光点提亮。 |
| 光影氛围 | **伦勃朗式布光**：单一暖光自斜上方打入，颊侧出倒三角亮区，四周暗角收束。 |
| 镜头构图 | 半身或胸像特写，平视或微仰，人物偏中心偏稳重。 |
| 风格质感 | 油画布纹可见、笔触浑厚、色彩温润、年代感。 |
| MJ参数 | `--style raw --stylize 250 --ar 3:4`。 |

### 场景公式
| 槽位 | 取值口径 |
| --- | --- |
| 空间类型 | 室内：画室、书房、厅堂、教堂内景。 |
| 建筑结构 | 厚重帷幔、木护墙、石墙、拱顶；背景多暗调简省。 |
| 材质纹理 | 木纹、石面、织绒——以颜料厚薄表现，反光克制。 |
| 光影氛围 | 暗调包围、局部暖光、明暗对照法主导。 |
| 叙事道具 | 烛台、帷幔、静物、卷轴、地球仪，点明身份与时代。 |
| 镜头构图 | 纵深封闭空间，背景隐入暗部。 |
| 天气时间 | 室内烛光/窗侧天光，多为昏暗午后或夜晚。 |
| 风格质感 | 古典主义、油彩厚重、博物馆质感。 |
| MJ参数 | `--style raw --stylize 300 --ar 16:9`。 |

### 人景融合公式
| 槽位 | 取值口径 |
| --- | --- |
| 景别构图 | 中景/胸像，人物居中偏稳重，暗角收边。 |
| 人物锚点 | 保留唯一锚点（如左耳珍珠耳坠、颊侧泪痣）+ 古典骨相。 |
| 动作落脚点 | 手扶书脊、坐于雕花椅、立于窗侧，重心落定、姿态端庄。 |
| 空间前后景 | 人物亮部在前、背景沉入暗部；前景可有帷幔或桌沿。 |
| 光影统一 | 全画面共用斜上方暖光源，人物亮部与背景受光物同源；暗部统一近黑。 |
| MJ参数 | `--ar 3:4 --style raw --stylize 250`。 |

## 二、印象派油画（impressionist-oil）

**媒介内核**：碎笔触 + 外光捕捉 + 补色并置；不描轮廓，用色点拼出形体与光。

### 服装公式
| 槽位 | 取值口径 |
| --- | --- |
| 颜色 | 高饱和分解色：阳光下的橙、天光下的紫蓝、草地的黄绿；阴影用互补色（紫/蓝）而非黑。 |
| 材质 | 轻盈织物、草帽纱巾；不画质感而画"光在料子上的碎色"。 |
| 款式 | 19世纪外光生活装：宽裙、束腰洋装、草帽、披肩。 |
| 细节设计 | 不用线条描边，用碎色点堆花纹、用亮冷点并置表现蕾丝透光。 |
| 工艺特征 | 短促破碎笔触、点彩并置、留空隙露底、不做平滑过渡。 |
| 整体风格 | 明快、流动、空气感、瞬间光色。 |
| MJ参数 | `--style raw --stylize 300 --ar 2:3`。 |

### 人物公式
| 槽位 | 取值口径 |
| --- | --- |
| 基础身份 | 郊游女子、花园青年、河畔闲坐者；气质松弛、生活化。 |
| 面部特征 | 不精勾五官，色块暗示结构；受光面暖、背光面冷紫，"光斑落在脸上"。 |
| 身材体型 | 自然松弛，轮廓模糊融于环境。 |
| 发型妆容 | 发丝化为一撮撮亮冷笔触，无清晰发际线。 |
| 服装细节 | 用服装公式的碎色点，衣摆边缘"散开"融入背景光。 |
| 饰品道具 | 阳伞、花束、草编篮。 |
| 光影氛围 | 户外正午/午后斑驳光，明暗皆有色、绝无纯黑。 |
| 镜头构图 | 抓拍式随意构图，人物常偏离中心。 |
| 风格质感 | 厚薄不均笔触、画布留白呼吸、色彩颤动。 |
| MJ参数 | `--style raw --stylize 350 --ar 3:4`。 |

### 场景公式
| 槽位 | 取值口径 |
| --- | --- |
| 空间类型 | 户外：花园、田野、河岸、林荫道、咖啡馆外座。 |
| 建筑结构 | 若有建筑也融为色块（白墙泛蓝紫、屋顶泛橙）。 |
| 材质纹理 | 草地/水面用短促排点和横向碎笔，水面以水平碎色写波光。 |
| 光影氛围 | 外光主导，光斑跳跃，影子偏蓝紫。 |
| 叙事道具 | 阳伞、野餐布、摇椅、小船。 |
| 镜头构图 | 横向开阔、地平线抬高或压低，留天空。 |
| 天气时间 | 晴朗正午、微风午后、黄昏暖光。 |
| 风格质感 | 笔触松散、色彩鲜活、空气颤动。 |
| MJ参数 | `--style raw --stylize 350 --ar 16:9`。 |

### 人景融合公式
| 槽位 | 取值口径 |
| --- | --- |
| 景别构图 | 中远景生活场景，人物与环境用同套碎笔统一。 |
| 人物锚点 | 保留标志性色块（如那把红白阳伞、草帽白条）。 |
| 动作落脚点 | 坐草地、撑伞漫步、临水而坐，姿态松散自然。 |
| 空间前后景 | 前后景皆以笔触虚实区分（近景笔大、远景笔碎），非靠清晰焦外。 |
| 光影统一 | 全画同一外光源，人物身上光斑方向与环境树影一致；影皆偏蓝紫。 |
| MJ参数 | `--ar 16:9 --style raw --stylize 350`。 |

## 三、水彩风（watercolor-art）

**媒介内核**：透明叠色 + 水的流动晕染 + 留白；重者叠多层、轻者一笔淡彩，白靠纸留不靠画。

### 服装公式
| 槽位 | 取值口径 |
| --- | --- |
| 颜色 | 清透淡彩、同色系深浅叠色；白靠留白；边缘自然晕开、有水痕。 |
| 材质 | 薄纱、棉麻、雪纺等"透气"料；用淡色透明叠层表现薄透，重色仅压暗部。 |
| 款式 | 唯美飘逸款：长裙、汉服、和风振袖、薄纱披帛。 |
| 细节设计 | 花纹以"湿画法"晕出柔和花影；边缘留水渍毛边。 |
| 工艺特征 | 湿接湿晕染、干叠加深、留白胶或干笔留高光、纸纹透出。 |
| 整体风格 | 清新淡雅、轻盈通透、文艺古风。 |
| MJ参数 | `--style raw --stylize 200 --ar 2:3`。 |

### 人物公式
| 槽位 | 取值口径 |
| --- | --- |
| 基础身份 | 古风仕女、少女、仙气角色；气质清雅温柔。 |
| 面部特征 | 淡彩淡描，肤色一层淡暖晕，腮颊一点胭脂自然洇开；结构靠色不靠线。 |
| 身材体型 | 纤秀轻盈，轮廓柔融。 |
| 发型妆容 | 发以淡墨蓝或淡赭湿染，边缘羽化，无根根分明。 |
| 服装细节 | 调用服装公式，强调透明叠层与留白。 |
| 饰品道具 | 一支花、纸伞、玉簪，淡彩点出。 |
| 光影氛围 | 柔光高调、无强阴影，暗部也保持透明色而非压黑。 |
| 镜头构图 | 全身或半身留白构图，人物可置于一角大量留白。 |
| 风格质感 | 透明水彩、水痕、留白、纸纹、飞白。 |
| MJ参数 | `--style raw --stylize 200 --ar 3:4`。 |

### 场景公式
| 槽位 | 取值口径 |
| --- | --- |
| 空间类型 | 园林、庭前、水畔、远山、雨巷等诗意场景。 |
| 建筑结构 | 亭台、回廊、石桥以淡线或淡色暗示，常大量留白为云/水/雾。 |
| 材质纹理 | 石、木以淡色轻扫；水用横向淡彩晕开。 |
| 光影氛围 | 清淡柔光，无重投影；靠留白做高光。 |
| 叙事道具 | 落花、薄雾、孤舟、飞檐一角。 |
| 镜头构图 | 计白当黑、留白即意境，构图疏朗。 |
| 天气时间 | 晨雾、雨后、薄暮、烟岚。 |
| 风格质感 | 透明、晕染、留白、纸纹。 |
| MJ参数 | `--style raw --stylize 250 --ar 16:9`。 |

### 人景融合公式
| 槽位 | 取值口径 |
| --- | --- |
| 景别构图 | 全景留白构图，人物小而环境疏朗。 |
| 人物锚点 | 保留标志淡色（一袭青绿披帛、一点朱砂唇）。 |
| 动作落脚点 | 立于桥畔、倚栏、撑伞，姿态轻盈但落点明确。 |
| 空间前后景 | 以"干湿浓淡"分前后景：近景湿色浓、远景淡而枯，靠水彩层次而非镜头虚化。 |
| 光影统一 | 柔光同调，人物与环境的留白方向一致（光从留白处来）。 |
| MJ参数 | `--ar 16:9 --style raw --stylize 250`。 |

## 四、素描 / 速写（sketch-draw）

**媒介内核**：单色（铅笔/炭笔）+ 排线塑形 + 黑白灰关系；结构严谨，靠线条疏密与擦揉表现体积。

### 服装公式
| 槽位 | 取值口径 |
| --- | --- |
| 颜色 | 无固有色，只有黑白灰阶；色度一律转成"明度—排线密度"。 |
| 材质 | 用排线方向与疏密暗示：硬料用直挺排线，软料用顺褶弧线，绒料用擦揉成面。 |
| 款式 | 结构清晰款，强调衣纹走向与体块转折。 |
| 细节设计 | 衣褶作"主线定形 + 副线补褶"；高光靠留白、暗部靠叠线与纸擦笔揉暗。 |
| 工艺特征 | 排线、交叉线、擦笔过渡、留高光橡皮提亮、可保留辅助构造线。 |
| 整体风格 | 结构严谨、艺术习作感、手绘痕迹。 |
| MJ参数 | `--style raw --stylize 150 --ar 2:3`。 |

### 人物公式
| 槽位 | 取值口径 |
| --- | --- |
| 基础身份 | 习作人像、模特、角色设定稿；气质中性客观。 |
| 面部特征 | 以明暗五调子塑形：亮面/灰面/明暗交界/反光/投影；结构线交代五官体块。 |
| 身材体型 | 比例严谨（头身/动态线准确），肌肉骨骼靠体块概括。 |
| 发型妆容 | 头发以成组暗部面块 + 留亮丝表现，不勾单根。 |
| 服装细节 | 调用服装公式，强调排线承载体块。 |
| 饰品道具 | 以黑白灰如实概括，不抢主体。 |
| 光影氛围 | 单一光源，明暗交界线明确，投影清晰。 |
| 镜头构图 | 半身/全身结构像，可附动态草图与局部放大。 |
| 风格质感 | 铅笔/炭笔颗粒、纸白留亮、排线方向可见。 |
| MJ参数 | `--style raw --stylize 150 --ar 3:4`。 |

### 场景公式
| 槽位 | 取值口径 |
| --- | --- |
| 空间类型 | 室内静物、街景速写、建筑透视习作。 |
| 建筑结构 | 透视严谨（一点/两点透视可留辅助线），结构线可见。 |
| 材质纹理 | 以排线疏密与方向区分木、石、布、金属。 |
| 光影氛围 | 单一明确光源，明暗面、投影、反光三要素完整。 |
| 叙事道具 | 静物组合、桌椅、杂物，概括再概括。 |
| 镜头构图 | 透视构图，可含视平线与消失点提示。 |
| 天气时间 | 以光源方向与投影长短暗示时间。 |
| 风格质感 | 单色、排线、擦揉、纸纹、草图线。 |
| MJ参数 | `--style raw --stylize 150 --ar 16:9`。 |

### 人景融合公式
| 槽位 | 取值口径 |
| --- | --- |
| 景别构图 | 中景速写，可保留构图辅助线/框。 |
| 人物锚点 | 以剪影与动态线保辨识，明暗交界位置固定为锚。 |
| 动作落脚点 | 动态线准确、重心落地（脚接地面、坐点受压衣纹）。 |
| 空间前后景 | 近景排线密而实、远景排线疏而虚，靠线密度分层。 |
| 光影统一 | 人物投影方向与场景投影方向严格一致，全画同一明暗体系。 |
| MJ参数 | `--ar 16:9 --style raw --stylize 150`。 |

## 五、版画（printmaking）

**媒介内核**：木刻/铜版——**只有黑与白两分**；灰靠刀路疏密（点/线群）幻视；硬朗、装饰、高对比。

### 服装公式
| 槽位 | 取值口径 |
| --- | --- |
| 颜色 | 纯黑白双色（或套色少数几色）；"颜色"槽转译为"此处留白还是刻黑"。 |

## 十、公式化落地心法

1. **先锁媒介，再填内容**：艺术类的第一步是选定"媒介识别词"（见上表第二列），它决定后面每一格怎么写；同一件汉服，油画写"厚堆颜料堆出褶的明暗"，壁画写"平涂石青色块 + 描金铁线"，槽位相同、取值互斥。
2. **把"颜色/材质/皮肤"全部翻译成媒介语言**：服装"颜色"槽在版画里应填"此处刻黑/此处留白"，人物"皮肤"在素描里应填"明暗五调子 + 排线疏密"，在水彩里应填"一层淡暖晕 + 胭脂点洇"——**永远不要直接写真实肤质**。
3. **光影槽是艺术类风格开关**：古典油画→伦勃朗暗角、印象派→户外碎光、素描→单光源明暗交界、版画→硬边黑白、壁画→平面装饰光、蛋彩→柔和微差、色粉→逆光绒边；填错光影槽，媒介就会串味。
4. **场景用"媒介分层"而非镜头景深**：艺术类的前后景不靠浅景深虚化，而靠各自的媒介手段——水彩用干湿、素描用线密度、版画用黑白实虚、色粉用粉层厚薄、壁画用上尊下卑平面层级。
5. **人景融合必锁"光影同源"**：人物投影/受光方向必须与场景一致（伦勃朗暖光同源、印象派影皆偏蓝紫、素描投影同向），否则出现"拼贴感"。
6. **stylize 随媒介走**：结构越严谨（素描/速写）取 150 听提示词；越重氛围晕染（印象派/壁画/色粉）取 250–350 让模型发挥艺术性；古典油画/蛋彩居中 250–300。

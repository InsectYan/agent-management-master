# 小说改编剧本指南

> 把小说改成剧本，本质上不是"缩写"，而是**把文学语言翻译成视听语言**：从"他怎么想"变成"观众能看到什么、听到什么、感受到什么"。

## 一、先把小说拆成"可拍的骨架"

拿到小说后，不要急着写台词，先做这几步：

1. **提炼一句话故事**
   谁，在什么处境下，想要什么，遇到什么阻碍，必须付出什么代价。
   如果一句话讲不清，说明主线还不够清晰。

2. **确定核心冲突**
   小说可以慢慢铺陈，剧本必须尽快让观众明白：主角要什么？谁在阻止他？失败会怎样？

3. **梳理人物弧光**
   主角不能只是经历事件，还要有变化：从懦弱到勇敢、从执念到放下、从自私到承担。

4. **砍掉不能拍的内容**
   大段心理描写不要删。能拍的写成神情变化，拍不出来的写成内心独白。作者议论和背景收进相关场次的编号，不要整段丢掉。

5. **按场景重组结构**
   小说按章节走，剧本按场景走。每个场景都要有功能：推进剧情、揭示人物、制造冲突、埋设伏笔或释放信息。

## 二、小说改剧本的具体改法

| 小说写法 | 剧本改法 | 示例 |
|---|---|---|
| 心理描写 | 神情变化，或一行内心独白 | "他很委屈"→神情从咬唇变成低头；或内心独白：「凭什么是我」 |
| 作者旁白 | 改成可见细节或对话 | "他们关系破裂"→两人同屋却互不交谈 |
| 大段背景 | 拆成冲突中自然带出 | 用争吵、审问、回忆揭示过去 |
| 抒情段落 | 压缩成意象或沉默 | 雨、空椅子、未接来电代替长篇感慨 |
| 多线叙事 | 合并主线，删冗余支线 | 保留最能推动冲突的线索 |

## 三、合格剧本的基本格式

剧本不是散文，它有行业标准。一个合格剧本至少要做到：

- **场景标题清楚**：内/外景 + 地点 + 时间，例如"内·咖啡馆·夜"。
- **只写可拍内容**：不写"他心里很痛苦"，要写"他低头，手指发抖"。
- **人物首次出现要清晰**：名字、年龄感、身份、状态简要交代。
- **台词口语化**：符合人物身份，不说书面腔、不说教。
- **动作描述简洁**：不要堆形容词，更不要替导演写镜头调度。
- **篇幅可控**：标准剧本一页大约对应一分钟银幕时间。

## 四、什么样的剧本才算"好剧本"

好剧本不只是故事好看，更要**可拍、可演、可信、有情绪回报**。

可以从这几个标准判断：

1. **故事前提成立**
   能用一句话讲清主角目标、阻碍和代价。

2. **结构有因果链**
   事件不是流水账，而是"因为A，所以B；因为B，所以C"。

3. **人物有欲望和缺陷**
   主角想要什么、怕什么、缺什么，必须清楚。

4. **冲突持续升级**
   障碍越来越难，选择越来越痛，代价越来越大。

5. **每场戏都有用**
   这一章的情节都要留下。删掉一场如果前后接不上，这场就不能删，也不能并进别的场充数。

6. **台词有潜台词**
   人物说的和真正想要的之间要有张力，不要直白解释一切。

7. **用画面讲故事**
   关键信息尽量通过动作、道具、环境、表情呈现。

8. **节奏有起伏**
   紧张—松弛—更紧张，不能一直平，也不能一直炸。

9. **主题自然浮现**
   主题不是喊口号，而是通过人物选择和后果体现。

10. **制作上可行**
    场景、人物、特效要与预算匹配，尤其是短剧、网剧更要注意成本。

## 五、如果是改短剧，要更强调节奏

短剧改编通常要：

- 开篇尽快进入冲突；
- 每集有明确目标；
- 每集结尾留钩子；
- 人物不宜过多；
- 场景尽量集中；
- 爽点、反转、情绪点要密集。

但无论电影、电视剧还是短剧，底层原则一样：**人物可信、冲突成立、节奏有效、画面可拍、结尾有余味**。

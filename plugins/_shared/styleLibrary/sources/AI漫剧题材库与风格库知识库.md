# AI 漫剧视觉资产 · 题材库与风格库知识库

> 本手册分两大维度：**题材库**（决定"画什么"，即内容与视觉美学）与**风格库**（决定"怎么画出来"，即渲染引擎与质感）。两者可自由叠加，例如"3D 古风国漫 + MJ 渲染"或"赛博朋克 + 2.5D 半写实渲染"。每个条目均按"服装 → 人物 → 场景 → 人景融合 → 参数"的资产结构展开，可直接作为大模型抽取小说文本的结构化模板。

---

## 第一部分：题材库（内容美学维度）

### 题材一：3D 古风国漫

**核心定位**：以东方传统美学为内核，采用 3D 三维建模渲染质感呈现的国风动画风格。介于真人写实与二维动画之间，强调立体体积感、皮肤与发丝的真实光照、以及服饰布料的物理垂坠。代表参照：《斗罗大陆》《完美世界》《眷思量》等国漫番剧。

#### 1. 服装资产细节

- **形制款式**：交领右衽长袍、对襟大袖衫、齐胸襦裙、曲裾深衣、圆领袍、马甲比甲、披风帔帛、宽袖道袍、武弁劲装、铠甲护心镜。
- **层次结构**：中衣 + 中袍 + 外衣 + 披帛/披风，多层叠穿；袖口、领缘、衣摆多层镶滚。
- **面料材质**：云锦、蜀锦、缂丝、杭绸、杭缎、罗纱、轻绡、素纱、暗花绫；外袍挺括有骨感，内衬柔软贴身，披帛轻薄透光。
- **纹样工艺**：云龙纹、祥云纹、缠枝莲、海水江崖、仙鹤衔芝、饕餮纹、忍冬纹、缠枝牡丹；金线盘金绣、苏绣平针、贴金箔、钉珠、点翠、缂丝织金。
- **色彩体系**：朱红配鎏金、玄黑配暗金、月白配靛青、黛蓝配银、藕荷配月白、鸦青、秋香色、石青、胭脂；主色沉稳 + 金/银点缀提亮。
- **配饰细节**：玉带钩、腰间玉佩、香囊、宫绦流苏、护腕、绑腿、革带、披帛、云肩、发冠配玉簪、抹额、面具。

#### 2. 人物资产细节

- **脸型骨相**：鹅蛋脸/瓜子脸，下颌线流畅，东方柔和骨相，颧骨内敛，面部饱满不过分立体。
- **五官特征**：丹凤眼/桃花眼，眼尾上扬，卧蚕明显，瞳色深褐；柳叶眉/远山眉；鼻梁挺直秀气；唇形小巧，樱桃唇、咬唇妆感。
- **皮肤质感**：冷白皮或暖玉色，瓷感细腻，3D 次表面散射（SSS）呈现微透红润，毛孔与真实皮肤肌理细腻。
- **发型发质**：男性束发戴冠、半束半披、高马尾、龙须刘海；女性飞天髻、双环垂髻、垂鬟、空气感长发；发丝根根分明，带 3D 发丝渲染高光。
- **妆容风格**：男性清透修容强调骨相；女性花钿、斜红、酒窝妆、大地色眼妆、水光唇。
- **身材体型**：男性修长挺拔、宽肩窄腰、九头身；女性身姿婀娜、腰肢纤细、比例修长。
- **唯一锚点（防变脸）**：必须固定 1-2 个排他性特征，如"眉心一点朱砂"、"右眼角泪痣"、"左耳红绳耳坠"、"额间银色花钿"。

#### 3. 场景资产细节

- **空间类型**：宫廷大殿、竹林庭院、悬空仙侠云海、悬崖仙府、江南水乡、塞外孤城、地宫古墓、桃花谷。
- **建筑风格**：飞檐斗拱、歇山顶、歇山式楼阁、朱红宫墙、汉白玉栏杆、月洞门、回廊、牌楼、亭台水榭、悬空栈道。
- **材质纹理**：雕花楠木、青砖黛瓦、琉璃瓦反光、汉白玉、鎏金铜饰、石阶青苔、宣纸窗棂、青铜器锈蚀。
- **光影氛围**：晨雾丁达尔光、夕阳穿林暖光、月光清冷、烛火摇曳、灯笼暖光、云海反射柔光；空气透视强，远山层叠。
- **叙事道具**：石桌棋盘、古琴、香炉青烟、飘落桃花瓣、悬空的剑、案上竹简、随风灯笼、池锦鲤、飞舞的纱幔。
- **天气时间**：烟雨江南、大雪压松、月明星稀、云破日出、 foggy 清晨、雷云压境。

#### 4. 人景融合构图要点

- 给动作找物理落脚点（"盘坐于悬空石台"、"衣袂踩在云海之上"、"足尖点在飘落竹叶上"）。
- 用前景遮挡（竹叶、纱幔、花瓣）营造纵深与仙气。
- 统一光源方向，披帛与发丝的飘动方向要与环境风/光一致。
- 常用大远景展现仙侠世界观，或中近景突出情绪。

#### 5. MJ 参数建议

`--ar 9:16`（人物立绘）/ `--ar 16:9`（场景）；`--style raw`（还原建模质感）；`--stylize 200-350`（平衡华丽度与还原度）；`--cref`（锁角色脸）；`--sref`（锁国漫渲染风格）。

### 题材二：2.5D 半写实 + 赛博朋克

**核心定位**：2.5D 指介于二维手绘与三维写实之间的中间渲染质感——保留赛璐璐/厚涂的手绘笔触与描边感，同时具备体积光影与半写实的五官比例。叠加"赛博朋克"题材（高科技 + 低生活的反乌托邦美学）。两者是"渲染档位 + 内容题材"的叠加。

#### 1. 服装资产细节

- **形制款式**：机能风战术夹克、改良旗袍 / 机能汉元素、露腰短上衣 + 工装裤、连体战斗服、透明雨衣外套、oversize 军规风衣、半透明机能马甲、束腿战术裤 + 高帮靴。
- **材质质感**：做旧皮革、反光涂层尼龙、PVC 透明材质、碳纤维硬壳、金属链甲、液态金属、半透明发光面料、防水涂层、磨砂金属件。
- **发光装饰**：LED 光带（沿衣缝走向）、胸口发光徽章、荧光管线、霓虹滚边、全息投影贴片、可变色光条。
- **色彩体系**：冷底（黑/深灰/藏青）+ 高饱和霓虹点缀（品红、青蓝、紫、荧光绿、橙）；单侧撞色；暗部保留冷蓝环境光。
- **工艺细节**：拉链堆叠、多口袋束带、磁吸扣、外挂弹匣/数据模块、破损与烧灼痕迹、涂鸦喷涂、二维码 / 电路纹理印花。
- **配饰道具**：全息耳机、增强现实 AR 眼镜、机械义肢手臂、发光颈环、数据接口项圈、电子纹身、机械义眼、悬浮无人机、武士刀、能量手枪。

#### 2. 人物资产细节

- **脸型骨相**：半写实比例——比纯二次元更立体、比真人更干净；棱角清晰的下颌线，立体鼻梁，保留手绘描边的轮廓。
- **五官特征**：锐利电子瞳（发光虹膜、义眼、异瞳）、机械感眼线、几何纹身、面部植入金属条、苍白或冷调肤色配霓虹高光。
- **皮肤质感**：半写实皮肤——保留体积光影与次表面散射，但抹除大部分真人瑕疵，呈现干净"渲染皮肤"；面部被霓虹反射成双色（一侧品红一侧青蓝）。
- **发型发质**：不对称短发、湿发造型、荧光挑染、剃边刻线（undercut）、脏辫配发光珠、齐刘海波波头、银白/粉紫染发；发丝带手绘高光块。
- **妆容风格**：赛博姬/赛博朗——发光眼影、荧光唇、面部电路彩绘、金属贴片、机械拼接妆。
- **身材体型**：精瘦肌肉线条、义体改造部位（发光接缝）、矫健、纹身覆盖率高。
- **唯一锚点**：如"左脸一道发光义体接缝"、"颈侧条形码纹身"、"机械右臂"、"额头单只红色义眼"。

#### 3. 场景资产细节

- **空间类型**：九龙城寨式垂直贫民窟、雨夜后巷、霓虹商业街、地下义体诊所、天台俯瞰城市、数据服务器机房、磁悬浮轨道、废弃工厂。
- **建筑结构**：密集管道与外挂空调、巨型全息广告、摩天楼与底层贫民窟的垂直落差、空中连廊、铁丝网、集装箱堆叠、繁体中文/日文霓虹招牌。
- **材质纹理**：湿滑柏油路反光、生锈金属、混凝土水渍、霓虹在湿地面的镜面倒影、蒸汽、玻璃幕墙、电缆缠绕。
- **光影氛围**：阴雨夜主基调，霓虹为主光源（品红 + 青蓝双色补光），硬阴影 + 高对比，体积雾/光，地面水洼反射，屏幕冷光。
- **叙事道具**：散落的数据线、全息投影广告循环播放、冒着蒸汽的拉面摊、闪烁故障的招牌、积水中倒映的霓虹、悬浮出租车光轨、墙上的涂鸦标语。
- **天气时间**：永夜 + 酸雨、雷暴、浓雾、霓虹反射的彩色雨幕。

#### 4. 人景融合构图要点

- 让人物踩在积水地面并生成倒影，是消除"抠图感"的关键落脚点。
- 霓虹双色光必须同时打在人物的左右两侧脸/身上，与环境光统一。
- 用前景雨滴、蒸汽、栏杆虚化增强纵深与电影感。
- 常用广角仰拍表现赛博城市的压迫感，或中景浅景深突出人物情绪。

#### 5. MJ 参数建议

`--ar 16:9`（场景）/ `--ar 9:16`（人物）；`--style raw`（避免过度美化成"科幻大片"，保留赛博的破败压抑）；`--stylize 150-300`；`--cref`（锁脸/义体）；`--sref`（锁 2.5D 半写实渲染质感）。

## 第二部分：风格库（渲染引擎 / 质感维度）

> 风格 ≠ 题材。以下是"渲染引擎/质感"选项，可与任意题材自由叠加。Midjourney 是主打工具，其默认美化倾向即俗称的"MJ 风格"；此外还有多种可选的渲染质感。

### 一、Midjourney 风格（主打，含默认渲染倾向）

**本质**：Midjourney 不是某种美术流派，而是其默认算法渲染倾向——自动附加电影级光影、超高细节、强烈材质质感与艺术化构图。通过参数可调节这种倾向的强弱。

**关键参数体系（细节速查）**：

- `--style raw`：关闭默认美化，还原真实/建模质感，适合需要精准还原款式的场景。
- `--stylize <数值>`（旧称 `--s`，0-1000，默认 100）：控制艺术化程度。低值（100-200）忠实提示词、更写实；高值（400-800）画面更华丽、更有"大片感"。
- `--chaos <0-100>`：出图多样性/随机性，值越高四张图差异越大。
- `--q <1 / 2>`（部分版本）：渲染质量档位，2 强化纹理细腻度。
- `--ar 宽:比`：画幅比例。9:16/2:3 竖版立绘，16:9/21:9 横版场景。
- `--cref <链接>`（Character Reference）：锁定角色一致性，防变脸，配合 `--cw 0/50/100` 控制参考权重（脸/服装/姿态）。
- `--sref <链接>`（Style Reference）：锁定画面渲染风格质感，配合 `--sw` 控制风格权重。
- `--no <词>`：负向排除（如 `--no 文字, 多余手指`）。
- `--tile`：生成可无缝平铺的纹理，适合做材质贴图。
- `--w / --blend`：多参考图混合。
- `--v 版本号 / --niji 版本号`：切换基础模型版本或切到二次元专用 Niji 模式。

**调优建议**：想要"纯正题材味"（赛博的阴冷、古风的清雅）而非被 MJ 美化成通用大片，就降 `--stylize` 并加 `--style raw`；想要商业海报级惊艳质感则升 `--stylize`。

### 二、Niji 二次元风格（MJ 的动漫专用线 / Niji journey）

- **视觉特征**：纯正日式赛璐璐动画质感，干净描边、平涂大色块、动漫五官比例、强调眼神高光与发丝动漫化处理。
- **适用题材**：古风国漫的二次元版、日系轻小说插画、清新日常、奇幻番剧。
- **提示词关键**：`anime style, cel shading, clean lineart, flat colors, sharp anime eyes, vibrant palette`。
- **控制方式**：Midjourney 内 `--niji 6`；或独立 Niji journey；权重靠 `--style` 与描述词。

### 三、Stable Diffusion 风格（本地模型 / LoRA / Checkpoint 驱动）

- **视觉特征**：风格完全由所选底模（Checkpoint）与外挂 LoRA 决定，可精准复刻某画师、某 IP、某种画风，可控性最强（配合 ControlNet 控制构图/姿态/线稿）。
- **适用题材**：全题材通吃，尤其适合需要严格画风一致、批量出图、角色固定的项目管线。
- **提示词关键**：靠"触发词 + 权重语法 `(keyword:1.2)` + 负面提示"控制；如 `masterpiece, best quality`、画师名 LoRA 触发词。
- **控制方式**：Checkpoint（大风格）→ LoRA（细分画风/角色）→ ControlNet（构图骨架）→ 采样器/步数/CFG。

### 四、写实摄影风格（Photorealistic）

- **视觉特征**：逼近真实照片——真实皮肤毛孔、景深虚化、镜头光学缺陷、自然光。
- **提示词关键**：`photorealistic, shot on Sony A7R IV, 85mm lens, f/1.8, natural lighting, skin pores, hyperrealistic, 8k, RAW photo`。
- **适用题材**：真人质感定妆照、产品图、现代都市场景。

### 五、吉卜力 / 宫崎骏动画风格

- **视觉特征**：手绘水彩背景、清新自然色调、圆润造型、云朵与植物的通透质感、温暖治愈氛围。
- **提示词关键**：`Studio Ghibli style, hand-painted watercolor background, Miyazaki, soft pastel colors, lush nature, whimsical`。
- **适用题材**：治愈系古风田园、奇幻冒险、清新日常。

### 六、新海诚电影风格

- **视觉特征**：极致通透的天空与光影、逆光与光斑、云层的体积感、写实背景 + 唯美光氛、高饱和蓝天。
- **提示词关键**：`Makoto Shinkai style, cinematic lighting, lens flare, hyperdetailed sky and clouds, volumetric light, bittersweet atmosphere`。
- **适用题材**：现代都市青春、情绪空镜、雨景与黄昏。

### 七、美式漫画 / 超级英雄风格

- **视觉特征**：粗黑描边、强对比阴影（墨块）、夸张肌肉与动态、网点/排线、高张力分镜。
- **提示词关键**：`American comic style, bold ink lines, halftone dots, dynamic pose, dramatic shadowing, Marvel/DC style, action splash page`。
- **适用题材**：热血战斗、超级英雄、硬派都市。

### 八、厚涂 / 伪厚涂风格

- **视觉特征**：模拟油画/数字厚涂笔触，色块堆叠塑造体积，弱化描边、强调明暗与质感，笔触明显。
- **提示词关键**：`impasto, thick paint texture, digital painting, visible brush strokes, painterly, no lineart, strong chiaroscuro`。
- **适用题材**：古风仙侠立绘、写实人物、暗黑题材。

### 九、赛璐璐（Cel Shading）风格

- **视觉特征**：硬边明暗分区、平涂大色块、清晰描边，典型的二维动画上色，干净利落。
- **提示词关键**：`cel shading, flat color, hard shadow edges, clean outlines, 2D anime flat color`。
- **适用题材**：二次元番剧、2.5D 的二维侧、清晰风格化角色。

### 十、像素 / 复古游戏风格

- **视觉特征**：低分辨率像素格、有限调色板、8/16-bit 复古游戏观感、抖动（dithering）渐变。
- **提示词关键**：`pixel art, 16-bit, retro game sprite, limited palette, dithering, isometric pixel`。
- **适用题材**：赛博朋克复古未来、独立游戏美术、潮流插画。

### 十一、水墨 / 国风写意风格

- **视觉特征**：宣纸质感、墨色浓淡晕染、留白写意、毛笔笔触、淡彩点染。
- **提示词关键**：`Chinese ink painting, sumi-e, ink wash, rice paper texture, negative space, brush calligraphy strokes, minimalist`。
- **适用题材**：纯古风、仙侠意境、武侠意境空镜。

### 十二、3D 皮克斯 / C4D 立体渲染风格

- **视觉特征**：圆润卡通比例、柔和全局光照、材质真实但造型可爱、电影级渲染、盲盒/手办质感。
- **提示词关键**：`Pixar style, 3D render, C4D, Octane render, soft global illumination, blind box figure, cute proportion, subsurface scattering`。
- **适用题材**：Q 版角色资产、IP 形象、轻松喜剧题材。

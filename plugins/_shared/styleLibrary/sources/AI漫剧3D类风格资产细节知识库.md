# AI 漫剧 3D 类风格资产细节知识库

> 本知识库属于「题材库 · 3D 类（漫剧）」分支，承接前序「服装 / 人物 / 场景 / 人景融合」四套公式。
> 每种 3D 子风格均按 **风格定位 → 服装资产 → 人物资产 → 场景资产 → 光影渲染 → 提示词与 MJ 参数** 六个维度展开，可直接作为大模型抽取小说文本的结构化模板，也可作为知识库检索字段。
> 使用方式：先选 1 个 3D 子风格锁定渲染基调，再叠加服装/人物/场景四套公式的关键词，最后用 `--cref`（锁人物）、`--sref`（锁风格/场景）保证跨镜一致。

---

## 通用约定：六大资产维度说明

| 维度 | 含义 | 防穿帮要点 |
| --- | --- | --- |
| 服装资产 | 形制、面料、配色、纹样、配饰 | 锁死主色与标志性单品，跨镜不换装 |
| 人物资产 | 骨相、五官、皮肤、发型、妆容、身材、唯一锚点 | 必须设 1–2 个排他性锚点（泪痣/疤痕/单侧耳饰） |
| 场景资产 | 空间类型、建筑结构、材质、天气时间 | 锁死建筑主体与地标，多视角一致 |
| 光影渲染 | 光源类型、全局光照、反射、氛围 | 人物与场景共用同一光源方向 |
| 提示词 | 可直接喂给模型的英文/中文关键词串 | 题材词 + 渲染词分层 |
| MJ 参数 | style raw / stylize / cref / sref 等 | 用参数控制美化程度与一致性 |

## 1. 3D 古风玄幻国漫（3d-guofeng-xuanhuan）

**风格定位**：《斗罗大陆》《完美世界》等国漫 3D 风格，角色建模精致，光影柔和，色彩饱和，仙侠修真世界观。

### 服装资产
- **形制**：交领右衽长袍、广袖流仙裙、束腰劲装、对襟外袍、云纹披帛、护腕束膊。
- **层次**：内衬中衣 + 主袍 + 外披/大氅三层叠穿，下摆飘逸拖地，袖口开衩见里料。
- **面料**：飘逸丝绸、流光锦缎、轻透欧根纱、暗纹提花罗缎，动态下垂坠感强。
- **纹样工艺**：云雷纹、饕餮纹、卷草纹、仙鹤祥云、金线刺绣、掐丝镶嵌、玉佩绶带。
- **配色**：仙门多用月白、青碧、霜蓝配金；魔修多用玄黑、暗紫、血红配银；高饱和不失通透。
- **配饰**：玉冠发簪、流苏步摇、储物玉佩、悬壶佩剑、护身灵符、束腰玉带。

### 人物资产
- **骨相**：东方古典骨相，面部圆润柔和，下颌收敛，轮廓立体但不硬朗。
- **五官**：丹凤眼/桃花眼、细长眉峰、挺秀琼鼻、樱桃唇，瞳色偏深或异色（金瞳/碧瞳显仙气）。
- **皮肤**：次表面散射（SSS）通透瓷感，柔光下泛莹润光泽，肤质细腻无瑕。
- **发型**：长发及腰、半束半披高发髻、仙气盘发配飘带，发丝根根分明带柔光边缘。
- **妆容**：清透仙气妆、淡晕眼影、点绛唇、面靥花钿，眉眼含情。
- **身材**：仙门弟子清瘦修长九头身，女修曲线柔美，男修肩宽腰窄挺拔。
- **唯一锚点**：眉心花钿/额间灵印、左眼角泪痣、单侧银质耳坠、锁骨处灵纹。

### 场景资产
- **空间**：悬浮仙山、云海峰峦、宗门大殿、竹林幽谷、洞天福地、瀑布飞流、上古遗迹。
- **建筑**：飞檐斗拱、朱红廊柱、汉白玉台阶、琉璃瓦顶、悬空栈道、青铜鼎炉。
- **材质**：温润玉石、青石苔痕、流动云雾、发光灵植、千年古木、缥缈烟岚。
- **天气时间**：晨雾云海、暮色晚霞、月明星稀、灵气缭绕、四季仙山流转。
- **叙事道具**：悬浮古剑、蒲团丹炉、飘落灵花瓣、法阵光纹、流光仙鹤。

### 光影渲染
- 柔和全局光照 + 体积云雾，轮廓柔光（Rim Light）勾勒仙气，粒子法术特效叠加，色彩饱和通透。

### 提示词与 MJ 参数
- **关键词**：3D 渲染，国漫美学，精致角色建模，飘逸汉服与丝绸质感，柔和全局光照，高饱和色彩，粒子法术特效，仙侠氛围，虚幻引擎5渲染，8K 高清。
- **参数**：`--ar 9:16`（定妆照）/ `--ar 16:9`（场景）；`--stylize 250-400`；`--cref` 锁角色；`--sref` 锁仙侠渲染调。

## 2. 3D 新三维国风（3d-neo-guofeng）

**风格定位**：融合传统国风美学与现代三维技术，典雅细腻，温润色彩（如《凡人修仙传》《眷思量》）。

### 服装资产
- **形制**：改良汉服、对襟褙子、宋制长衫、素雅道袍、宽袖深衣，剪裁考究含蓄。
- **层次**：素净中衣 + 清雅外衫，少层叠重装饰，讲究线条流畅与垂感。
- **面料**：哑光丝绸、素色棉麻、轻透纱罗、竹纤维质感，温润不反光。
- **纹样工艺**：留白为主，点缀水墨兰草、工笔花鸟、暗纹云纱、素色刺绣、青瓷开片纹。
- **配色**：莫兰迪低饱和国风色——月白、黛青、藕荷、藤黄、松绿、胭脂淡彩。
- **配饰**：素簪玉佩、简约束带、绢扇、竹笛、青玉扳指，少而精。

### 人物资产
- **骨相**：东方含蓄骨相，五官比例均衡，线条柔和内敛，气质温润。
- **五官**：细长柳叶眉、含情杏眼、秀鼻淡唇，神情宁静恬淡。
- **皮肤**：细腻皮肤纹理，温润如玉质感，柔漫反射，哑光瓷肌。
- **发型**：低挽发髻、素雅垂马尾、齐刘海或中分，发丝带柔顺高光。
- **妆容**：极淡素妆、自然唇色、眉眼清淡，突出"清水出芙蓉"气质。
- **身材**：修长匀称，姿态端庄，重心含蓄。
- **唯一锚点**：一缕别于耳后的银白发丝、腕间青玉镯、眉尾一颗淡痣。

### 场景资产
- **空间**：文人书房、竹林庭院、江南水乡、烟雨长桥、茶室梅园、空山幽谷。
- **建筑**：粉墙黛瓦、木格花窗、月洞门、曲水流觞、素雅木构。
- **材质**：青砖黛瓦、宣纸木窗、润泽青瓷、太湖石、湿润青苔、雨后积水。
- **天气时间**：烟雨江南、薄雾清晨、雪落梅枝、月照空庭，宁静诗意。
- **叙事道具**：书卷茶盏、古琴香炉、飘落竹叶、未干的墨迹、摇曳烛影。

### 光影渲染
- 类 C4D 渲染，柔漫反射主导，极简构图，留白充足，宁静高雅，色彩温润低对比。

### 提示词与 MJ 参数
- **关键词**：现代三维技术融合传统东方美学，温润如玉的材质感，典雅含蓄配色，细腻皮肤纹理，极简构图，宁静高雅氛围，类 C4D 渲染。
- **参数**：`--style raw` 抑制过度美化；`--stylize 150-250`；`--sref` 锁国风留白调。

## 3. 3D 现代风格（3d-modern）

**风格定位**：现代都市题材，贴近真实人物但略带美化，服装时尚，场景写实。

### 服装资产
- **形制**：西装外套、风衣大衣、卫衣棒球服、针织衫、高腰阔腿裤、百褶裙、连身连衣裙。
- **层次**：内搭 + 主装 + 外套（风衣/西装/皮衣）叠穿，符合真实穿搭逻辑。
- **面料**：真实布料解算质感——挺括西装料、柔软针织、牛仔丹宁、皮革、防风冲锋衣料。
- **纹样工艺**：纯色为主，格纹/条纹/字母印花点缀，拉链缝线口袋等结构细节清晰。
- **配色**：都市通勤色——黑白灰驼、莫兰迪色，搭配一至两件亮色单品。
- **配饰**：机械腕表、金属细链项链、通勤包、墨镜、贝雷帽、运动鞋/皮鞋。

### 人物资产
- **骨相**：半写实人物比例，真实骨相略带美颜，五官接近真人但精修。
- **五官**：自然眼型、清晰眉形、立体鼻梁，符合当代审美。
- **皮肤**：略带美颜的细腻皮肤质感，柔和 SSS，保留毛孔细节但无瑕。
- **发型**：时尚发型——狼尾、锁骨发、纹理短发、大波浪、利落马尾，发丝自然蓬松。
- **妆容**：自然通勤妆、伪素颜、雾面底妆、自然唇色。
- **身材**：真实亚洲人体比例，七至七半头身，自然挺拔。
- **唯一锚点**：单只耳环、虎牙、手腕一道疤、特定美甲款式。

### 场景资产
- **空间**：写字楼、地铁、咖啡馆、商业街、公寓、天台、便利店、地下车库。
- **建筑**：玻璃幕墙、霓虹招牌、斑马线、电梯厅、落地窗、开放式工位。
- **材质**：抛光地砖、磨砂玻璃、金属电梯、木质家具、柏油路面、湿润街道。
- **天气时间**：自然日光照明，清晨通勤、正午、黄昏都市、雨后街景反光。
- **叙事道具**：咖啡杯、笔记本电脑、共享单车、手机屏幕光、飘落传单。

### 光影渲染
- 自然日光照明为主，写实光影逻辑，真实布料与皮肤解算，略带美颜但不过度。

### 提示词与 MJ 参数
- **关键词**：现代都市 3D 风格，半写实人物比例，时尚现代服装，真实布料解算，城市街道背景，自然日光照明，略带美颜的皮肤质感。
- **参数**：`--style raw`；`--stylize 100-200`；`--cref` 锁真人形象。

## 4. 3D 赛博朋克（3d-cyberpunk）

**风格定位**：高对比霓虹色调，机械义体，未来都市，科技感与颓废感并存。

### 服装资产
- **形制**：机能战术服、机能马甲、连帽机能外套、不对称剪裁、紧身战斗服、长款风衣。
- **层次**：紧身内衬 + 战术背带/马甲 + 半透机能外套，多口袋多束带。
- **面料**：做旧皮革、反光涂层尼龙、PVC 半透、哑光战术织物、冷硬金属护片。
- **纹样工艺**：LED 发光灯带、全息标识贴片、警示条纹、电路板蚀刻、反光条。
- **配色**：青（teal）+ 洋红（magenta）霓虹主导，玄黑底色，电光蓝/荧光绿点缀。
- **配饰**：发光护目镜、机械义肢接口、颈环数据口、全息耳机、电子纹身。

### 人物资产
- **骨相**：半写实偏冷峻骨相，棱角分明，颓废而锋利。
- **五官**：电子义眼（发光瞳）、 cyber 眼线、机械改造痕迹，神情冷漠疏离。
- **皮肤**：渲染皮肤，部分区域为合成皮肤/金属义体接缝，霓虹打在脸上呈青红双色。
- **发型**：荧光挑染、湿发造型、利落短发、不对称剃边，带反光高光。
- **妆容**：赛博烟熏妆、发光眼线、金属唇、面部荧光涂装。
- **身材**：精瘦有力或机能改造身材，义体肌肉线条。
- **唯一锚点**：颈部接口编号、半张脸机械义体、右臂发光机械臂、后颈条形码。

### 场景资产
- **空间**：垂直贫民窟、霓虹商业街、地下义体诊所、雨中巷道、摩天楼顶、黑客机房。
- **建筑**：密集亚洲招牌、全息广告、管道林立、层叠违建、巨型塔楼与底层暗巷的垂直落差。
- **材质**：湿滑反光地面、生锈金属、霓虹灯管、积水倒影、蒸汽、塑料雨棚。
- **天气时间**：永夜、酸雨、浓雾、霓虹反射，几乎无自然光。
- **叙事道具**：全息投影广告、漂浮无人机、电线缠绕、地上的积水霓虹倒影、贩卖机。

### 光影渲染
- 青与洋红霓虹灯光主导，强烈明暗对比，潮湿地面反射，体积光，光线追踪，高细节机械结构。

### 提示词与 MJ 参数
- **关键词**：赛博朋克美学，青与洋红霓虹灯光，机械义肢，高科技低生活，潮湿地面反射，体积光，强烈明暗对比，未来都市背景，光线追踪，高细节机械结构。
- **参数**：`--style raw`（还原阴冷破败）；`--stylize 100-200`；`--sref` 锁霓虹色调。

## 5. 3D 科幻写实（3d-scifi-real）

**风格定位**：近未来科幻风格，硬表面建模，真实光影，强调科技感。

### 服装资产
- **形制**：太空服、战术装甲、科研制服、模块化功能服、飞行服、外骨骼承载服。
- **层次**：贴身功能层 + 装甲/设备承载层 + 外套，结构严谨模块化。
- **面料**：复合防弹织物、哑光金属板、工程塑料、凯夫拉、隔热涂层、碳纤维。
- **纹样工艺**：型号编号、警示标贴、密封接缝、卡扣管线、工业丝印 logo。
- **配色**：冷灰、军绿、白、橙红警示色，低饱和工业色，金属银点缀。
- **配饰**：头盔、面罩 HUD、战术手套、氧气/能量背包、对讲终端、身份芯片卡。

### 人物资产
- **骨相**：写实骨相，真实人体比例，专业航天员/军人/科学家气质。
- **五官**：坚毅真实五官，眼神专注理性，面部受舱内冷光影响。
- **皮肤**：真实皮肤质感，保留毛孔瑕疵，受定向硬光形成清晰阴影。
- **发型**：利落实用发型，束发戴头盔或短发，发丝受静电/微重力影响。
- **妆容**：无妆或防护面罩下淡妆，强调真实感。
- **身材**：真实健壮体能，符合职业（宇航/作战）体态。
- **唯一锚点**：面罩上划痕、手臂型号纹身、一道烧伤疤、胸前铭牌编号。

### 场景资产
- **空间**：太空舱、空间站、实验室、机库、行星地表基地、控制中枢。
- **建筑**：模块化舱体、对接环、透明观景穹顶、管线桁架、气闸门、机械臂。
- **材质**：拉丝金属、复合装甲板、强化玻璃、防滑甲板、冷凝水珠、密封橡胶圈。
- **天气时间**：舱内冷白照明；舱外恒星强光或行星地表荒凉光照，硬阴影。
- **叙事道具**：全息控制台、漂浮工具、屏幕数据流、培养舱、舷窗外的星空/行星。

### 光影渲染
- 硬表面建模，真实金属与复合材料质感，冷色调照明，工业设计风格，严谨光影逻辑，电影级渲染。

### 提示词与 MJ 参数
- **关键词**：硬表面建模，近未来科幻，真实金属与复合材料质感，冷色调照明，工业设计风格，严谨光影逻辑，太空或实验室场景，电影级渲染，8K。
- **参数**：`--style raw`；`--stylize 80-150`（追求真实克制）；`--sref` 锁工业冷调。

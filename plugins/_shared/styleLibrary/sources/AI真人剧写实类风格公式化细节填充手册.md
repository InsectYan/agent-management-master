# AI 真人剧 · 写实类风格「公式化」细节填充手册

> 本手册不重复堆砌风格描述，而是严格套用《视觉资产提示词公式手册》的**四大公式模块顺序**，针对 7 种写实类（真人剧）风格，逐字段给出「该公式的每个槽位，在这种风格下应该填什么细节」的取数口径。可直接作为知识库：把小说文本喂给大模型后，按对应风格的对应槽位召回细节、补全、组装成可执行生图提示词，并保证多集多镜一致。

---

## 〇、四大公式槽位框架（取数骨架，全风格通用）

| 公式 | 模块顺序（每个槽位都是一个待填字段） |
| --- | --- |
| 服装 | [颜色] + [材质] + [款式] + [细节设计] + [工艺特征] + [整体风格] + [MJ参数] |
| 人物 | 基础身份 + 面部特征 + 身材体型 + 发型妆容 + 服装细节 + 饰品道具 + 光影氛围 + 镜头构图 + 风格质感 + MJ参数 |
| 场景 | 空间类型 + 建筑结构 + 材质纹理 + 光影氛围 + 叙事道具 + 镜头构图 + 天气时间 + 风格质感 + MJ参数 |
| 人景融合 | [景别构图] + [人物锚点] + [动作落脚点] + [空间前后景] + [光影统一] + [MJ参数] |

> 写实类共性铁律（贯穿所有槽位）：① **皮肤质感是命门**——人物槽位优先写"自然皮肤纹理、可见毛孔、轻微雀斑、眼角细纹、细微油性高光"，禁用"完美面容/肌肤光滑"致塑料脸；② **实拍关键词锚定**——服装/场景/人物统一挂 `real photography`、`shot on ARRI Alexa`、`35mm film grain`、`RAW photo`、`shallow depth of field`，拒绝 CG/渲染；③ **先定人再拍片**——人物公式先出定妆照+三视图锁脸，再谈分镜。

## 一、商业摄影写实（commercial-photo）

> 定位：时尚杂志封面级，完美布光、精致妆容、皮肤细腻无瑕疵、景深虚化、色彩鲜艳、专业模特。**美化度最高一档。**

### 服装公式
| 槽位 | 该风格填充口径 |
| --- | --- |
| 颜色 | 高饱和纯色或大牌撞色（正红/宝蓝/爱马仕橙/经典黑白），色彩干净鲜明 |
| 材质 | 高定级真丝缎面、羊绒、漆皮、亮片、重工珠绣，光泽饱满 |
| 款式 | 高级定制礼服、廓形风衣、结构西装、鱼尾拖尾，剪裁利落挺括 |
| 细节设计 | 夸张肩线、深V、高开叉、镂空、不对称垂坠，强造型感 |
| 工艺特征 | 立体钉珠、手工压褶、金属扣、明线挺缝，"广告级无瑕" |
| 整体风格 | 时尚大片、T台定妆、奢侈品广告、杂志封面质感 |
| MJ参数 | `real photography, fashion editorial, shot on 85mm f/1.4 --style raw --stylize 150 --ar 2:3` |

### 人物公式
| 槽位 | 该风格填充口径 |
| --- | --- |
| 基础身份 | 专业超模/明星质感，气场自信，镜头表现力强 |
| 面部特征 | 骨相精致对称、妆容精致无瑕；但仍写"细腻真实肤质"避免塑料——取"精致但可信" |
| 身材体型 | 高挑修长、九头身、比例极佳，体态挺拔 |
| 发型妆容 | 精致造型发（湿发/大卷/利落盘发）、哑光高级妆、清晰眉形、饱满唇色 |
| 服装细节 | 调用服装公式成品，强调高定剪裁贴合 |
| 饰品道具 | 高级珠宝、腕表、造型手包，点睛不过量 |
| 光影氛围 | 完美三点布光/蝴蝶光，主光+轮廓光+反光板，肤光均匀 |
| 镜头构图 | 半身或全身棚拍，平视微仰，背景干净虚化 |
| 风格质感 | 高端镜头成像、色彩分级、商业广告级锐利 |
| MJ参数 | `--style raw --stylize 120 --ar 2:3 --cref 定妆照链接` |

### 场景公式
| 槽位 | 该风格填充口径 |
| --- | --- |
| 空间类型 | 影棚无缝背景纸/极简实景棚/高端置景 |
| 建筑结构 | 极简几何台、纯色墙面，弱建筑强氛围 |
| 材质纹理 | 哑光/丝绒背景布、抛光地面反光 |
| 光影氛围 | 主光柔和+边缘光勾勒，背景渐变光，无杂乱阴影 |
| 叙事道具 | 极少，仅点缀高脚杯/花艺/品牌道具，服务主体 |
| 镜头构图 | 中近景为主，浅景深虚化背景 |
| 天气时间 | 影棚无天气，色温按冷暖主题精确控制 |
| 风格质感 | 商业棚拍、广告大片、修图级洁净 |
| MJ参数 | `studio fashion shoot, seamless backdrop --style raw --stylize 150 --ar 2:3` |

### 人景融合公式
| 槽位 | 该风格填充口径 |
| --- | --- |
| 景别构图 | 全身/大半身定妆，中心或三分，背景纯净 |
| 人物锚点 | 调用定妆脸+高定服装锚点即可 |
| 动作落脚点 | 标准模特姿态：靠台/坐高脚凳/双手交叠，重心稳 |
| 空间前后景 | 人物前景实焦，背景纯色渐虚，无干扰 |
| 光影统一 | 棚光方向统一，轮廓光勾边，背景光分离主体 |
| MJ参数 | `--ar 2:3 --style raw --stylize 150` |

## 二、纪实摄影写实（documentary-photo）

> 定位：新闻/人文纪实，自然光、无修饰、真实皮肤纹理与皱纹、抓拍瞬间、35mm 胶片质感、人文关怀。**真实度最高、美化最低。**

### 服装公式
| 槽位 | 该风格填充口径 |
| --- | --- |
| 颜色 | 环境真实色、低饱和土色系（灰绿/卡其/旧蓝/洗白黑），不做作 |
| 材质 | 日常棉麻、旧牛仔、磨毛针织、工装帆布，带使用痕迹 |
| 款式 | 实用生活款：夹克、卫衣、工装、围裙、旧毛衣，宽松合身 |
| 细节设计 | 起球、磨白、缝线开裂、衣角卷边、口袋变形，"被生活穿过" |
| 工艺特征 | 无精致工艺，重真实褶皱与褪色；`weathered, worn-in fabric` |
| 整体风格 | 纪实人文、街头真实、劳动者/市井质感 |
| MJ参数 | `documentary photo, natural light, 35mm film grain --style raw --stylize 80 --ar 3:2` |

### 人物公式
| 槽位 | 该风格填充口径 |
| --- | --- |
| 基础身份 | 真实普通人：摊贩、工人、老人、孩童、路人，无表演感 |
| 面部特征 | 皱纹、晒斑、毛孔、胡茬、皮肤油光、不对称五官——**保留一切不完美** |
| 身材体型 | 真实体型：微驼、粗壮、瘦削，非模特比例 |
| 发型妆容 | 素颜或生活妆，乱发、油头、自然花白，无造型 |
| 服装细节 | 调用服装公式"旧衣"口径 |
| 饰品道具 | 生活实物：旧表、搪瓷杯、安全帽、购物袋 |
| 光影氛围 | 纯自然光，窗口光/街灯/阴天漫射，无补光 |
| 镜头构图 | 抓拍瞬间、平视、略歪构图，决定性瞬间 |
| 风格质感 | 35mm 胶片颗粒、纪实色调、人文关怀 |
| MJ参数 | `--style raw --stylize 60 --ar 3:2 --cref 人物定妆` |

### 场景公式
| 槽位 | 该风格填充口径 |
| --- | --- |
| 空间类型 | 街头/市场/工地/老巷/民居，实景非布景 |
| 建筑结构 | 斑驳墙面、电线缠绕、旧招牌、水泥地 |
| 材质纹理 | 锈铁、剥落漆、青苔、积尘、水渍，真实脏旧 |
| 光影氛围 | 自然天光/街灯/穿过窗的硬光，不修饰 |
| 叙事道具 | 散落实物：菜摊、工具、晾衣、烟头、积水，承载故事 |
| 镜头构图 | 中景/全景环境肖像，引导线、生活流构图 |
| 天气时间 | 真实天气：阴天/小雨/正午强光/黄昏，含时间感 |
| 风格质感 | 新闻纪实、去美颜、胶片颗粒 |
| MJ参数 | `street documentary, candid moment --style raw --stylize 60 --ar 3:2` |

### 人景融合公式
| 槽位 | 该风格填充口径 |
| --- | --- |
| 景别构图 | 环境肖像中景/全景，人物融入环境 |
| 人物锚点 | 锁定真实面容+旧衣，可含皱纹 |
| 动作落脚点 | 真实生活动作：搬货、蹲坐、行走、低头干活，双脚落地 |
| 空间前后景 | 人物与街景同实焦或环境略虚，前后景皆真实 |
| 光影统一 | 统一自然光源方向，环境色真实映射到人物 |
| MJ参数 | `--ar 3:2 --style raw --stylize 60` |

## 三、电影质感写实（cinematic-real）

> 定位：好莱坞剧照级，戏剧性布光、色彩分级、宽银幕、叙事性构图、高动态范围。**真实+强氛围调度。**

### 服装公式
| 槽位 | 该风格填充口径 |
| --- | --- |
| 颜色 | 服务角色身份与调色LUT：冷蓝/墨绿/暖褐/低对比灰，统一色彩分级 |
| 材质 | 真实但讲究：风衣羊毛、皮衣、湿透棉衬衫、脏污西装，材质承载叙事 |
| 款式 | 贴合人物设定（侦探风衣/工装/正装/战损服），有故事感 |
| 细节设计 | 雨水浸痕、泥点、磨损、褶皱，符合剧情情境 |
| 工艺特征 | 服化道级真实，做旧到位，`film costume, distressed` |
| 整体风格 | 电影剧照、宽银幕叙事、角色造型 |
| MJ参数 | `cinematic still, film lighting, color graded --style raw --stylize 180 --ar 21:9` |

### 人物公式
| 槽位 | 该风格填充口径 |
| --- | --- |
| 基础身份 | 角色化：侦探、特工、工人、幸存者，带情绪与动机 |
| 面部特征 | 真实肤质+戏剧微表情，汗珠、雨滴、伤妆按剧情 |
| 身材体型 | 角色合理体型，动作戏可写肌肉线条 |
| 发型妆容 | 服化道造型：湿发、凌乱、胡茬、战损妆，贴合情境 |
| 服装细节 | 调用服装公式做旧口径 |
| 饰品道具 | 叙事道具：枪支、警徽、怀表、香烟、对讲机 |
| 光影氛围 | 戏剧布光：伦勃朗光/侧逆光/霓虹侧光/车窗光，强明暗 |
| 镜头构图 | 宽银幕、过肩、低角度、浅景深、电影焦外 |
| 风格质感 | 好莱坞剧照、HDR、青橙/胶片LUT |
| MJ参数 | `--style raw --stylize 180 --ar 21:9 --cref 角色` |

### 场景公式
| 槽位 | 该风格填充口径 |
| --- | --- |
| 空间类型 | 叙事空间：雨夜街、废弃仓库、警局、公寓、车内 |
| 建筑结构 | 纵深感强：长廊、门框、窗、阶梯，引导视线 |
| 材质纹理 | 湿沥青、玻璃反射、金属、混凝土，电影级质感 |
| 光影氛围 | 体积光、丁达尔、霓虹反射、车灯光束，层次丰富 |
| 叙事道具 | 关键道具与悬念：烟头、血迹、文件、雨、烟雾 |
| 镜头构图 | 大远景定场/中景叙事，框架构图、引导线 |
| 天气时间 | 强氛围天气：暴雨/晨雾/夜雨/黄昏，服务情绪 |
| 风格质感 | 电影调色、宽银幕、HDR |
| MJ参数 | `movie scene, anamorphic lens --style raw --stylize 200 --ar 21:9` |

### 人景融合公式
| 槽位 | 该风格填充口径 |
| --- | --- |
| 景别构图 | 中景/过肩，三分或对称，叙事性最强 |
| 人物锚点 | 锁定角色脸+戏服+核心道具 |
| 动作落脚点 | 剧情动作：倚墙、握枪、撑伞、望向窗外，重心物理落地 |

## 四、人像精修写实（portrait-retouch）

### 服装公式
| 槽位 | 该风格填充口径 |
| --- | --- |
| 颜色 | 纯净高级色：白/米/灰/莫兰迪/单色，衬托肤色不抢戏 |
| 材质 | 干净质感：细针织、衬衫棉、哑光毛衣，弱装饰强质感 |
| 款式 | 简约上装/V领/衬衫/毛衣，服务脸部不分散注意 |

| 整体风格 | 影棚精修人像、头像/形象照质感 |
| MJ参数 | `professional portrait, studio lighting --style raw --stylize 120 --ar 4:5` |

### 人物公式
| 槽位 | 该风格填充口径 |
| --- | --- |

| 饰品道具 | 极简：小耳钉/细链，干净背景 |
| 光影氛围 | 柔光箱/反光伞主光+眼神光+轮廓光，肤光柔和过渡 |

| MJ参数 | `--style raw --stylize 120 --ar 4:5 --cref 定妆照` |

### 场景公式
| 槽位 | 该风格填充口径 |
| --- | --- |
| 空间类型 | 影棚纯色背景（灰/白/黑渐变） |
| 建筑结构 | 无，纯净背景 |
| 材质纹理 | 平滑无缝背景纸，柔和渐变 |
| 光影氛围 | 背景受光均匀，主体与背景明暗分离 |
| 叙事道具 | 无，纯净极简 |
| 镜头构图 | 胸像/头肩特写，浅景深 |

### 人景融合公式
| 槽位 | 该风格填充口径 |
| --- | --- |

## 五、RAW 风格写实（raw-photo）

> 定位：相机原片，中性色温、高动态范围、保留所有细节、无后期调色痕迹、真实色彩还原、原始底片质感。**忠实记录、零美化零渲染。**

### 服装公式
| 槽位 | 该风格填充口径 |
| --- | --- |
| 颜色 | 真实还原色、不过饱和、中性白平衡下的本色 |
| 材质 | 真实面料原貌：棉、牛仔、羊毛、化纤，纹理原样保留 |
| 款式 | 任意日常款，不造型、不做作 |
| 细节设计 | 原片如实记录：所有褶皱、线头、污渍一并保留 |
| 工艺特征 | 无修饰，`unretouched, straight out of camera` |
| 整体风格 | 相机原片、底片质感、高动态范围 |
| MJ参数 | `RAW photo, unedited, natural colors --style raw --stylize 60 --ar 3:2` |

### 人物公式
| 槽位 | 该风格填充口径 |
| --- | --- |
| 基础身份 | 真实人物，无摆拍设计 |
| 面部特征 | 原片级真实：毛孔、斑点、油光、细纹、肤色不均全保留 |
| 身材体型 | 真实体型，无美化 |
| 发型妆容 | 素颜自然、真实发丝与碎发 |
| 服装细节 | 调用服装公式原片口径 |
| 饰品道具 | 随身实物，如实记录 |
| 光影氛围 | 自然光原样，高动态范围保留亮暗细节，无打光 |
| 镜头构图 | 真实焦段透视，未裁切的自然构图 |
| 风格质感 | 原片直出、细节丰富、中性色调 |

## 九、公式化落地心法

1. **逐槽位填值再组装**：不要让模型自由发挥整句，而是按对应风格的对应公式表，逐格取数填入，最后按模块顺序拼成提示词——这是工程化一致性的根基。
2. **人物公式先固化**：写实类最怕"随机换脸"。先用「人像精修/商业摄影」口径出定妆照 + 三视图（纯白背景正脸特写+正侧背），存为 `--cref` 锚点，后续所有风格/分镜复用该脸。
3. **皮肤口径按风格分级**：纪实/RAW 写"毛孔、雀斑、皱纹、油光"全保留；商业/精修写"细腻均匀真实肤质"防塑料；电影/黑白写"戏剧明暗下的真实肌理"。
4. **风格切换只换槽位值不换结构**：同一人物公式，把"光影氛围/镜头构图/风格质感/MJ参数"四格换成目标风格的口径即可跨风格复用，降低重抽成本。
5. **场景与人物光影必须同源**：人景融合公式中"光影统一"槽位永远复述场景光源方向与色温，避免人景割裂。
6. **微距/黑白等特殊风格**：颜色槽位转灰阶或转纹理描述，构图槽位强调景深与明暗切割，是写实类里最依赖"公式逐格改写"的两种。

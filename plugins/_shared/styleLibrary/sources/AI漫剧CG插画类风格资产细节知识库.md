# AI 漫剧 CG/插画类风格资产细节知识库

> 本手册延续「视觉资产提示词公式手册」「题材库与风格库知识库」「3D 类风格资产细节知识库」，聚焦 **CG/插画类（漫剧）** 分支。
> 编写原则：**题材 / 风格决定「画什么 + 用什么笔触画」**。每种风格按统一的六个维度展开，可直接作为结构化模板，把小说文本喂给大模型按字段抽取补全后组装调用。
> 六维结构：**风格定位 → 服装资产 → 人物资产 → 场景资产 → 光影渲染 → 提示词与 MJ 参数**。

---

## 〇、总纲：插画类风格的三条共性心法

与 3D 类「靠建模与物理光照」不同，CG/插画类的画面完全由**笔触、上色逻辑与线条**决定。入库前先记住三条共性心法：

- **笔触即质感**：插画不像 3D 有真实材质，所有「布料、金属、皮肤」的质感全靠画师笔触模拟。所以写服装时，重点是「用什么笔触、什么上色方式表现这块布料」，而非「这块布料物理上是什么」。
- **描边决定流派**：有无外轮廓线（描边）、线条粗细与虚实，是区分厚涂、薄涂、矢量、钢笔淡彩等流派的第一开关。入库人物时务必声明「描边 / 无描边 / 线稿风格」。
- **光影可自由夸张**：插画不受物理光照约束，光影服务于情绪与叙事，可以「为情绪加一束不合逻辑的逆光」「用色彩冷暖分区」。这是插画相对 3D 的最大自由度，也是写「光影渲染」时的发力点。

## 一、厚涂写实（impasto-real）

### 风格定位
插画师厚涂技法：以数字笔刷模拟油画堆叠颜料，**有笔触感但造型高度写实**，无明显描边，靠色块堆体积。概念设计、游戏原画主流，气质厚重、专业、成人向。

### 服装资产
- **形制**：不限题材（奇幻铠甲 / 近代军装 / 都市外套皆可承载），重点在「结构交代清楚」。
- **面料表现**：用块面而非纹理贴图表现——亮部一笔厚堆、暗部一刀抹开；皮革用大块高光+硬反光，呢绒用哑光灰阶堆叠。
- **配色**：低到中饱和、偏灰调的「概念色」，主次色明确，常用土黄、锈红、青灰、墨绿。
- **细节**：磨损、油污、缝线、金属划痕用笔触点出，强调「用过的痕迹」。

### 人物资产
- **骨相**：写实比例，强调骨骼体块的明暗转折（颧骨、下颌、鼻梁结构清晰）。
- **五官**：靠明暗塑形而非线勾，眼窝、鼻底、唇线用色块暗示。
- **皮肤**：厚涂过渡，保留笔触与冷暖副色（受光偏暖、背光偏冷青），不做 3D 的 SSS，但靠颜色呼吸感显活。
- **锚点**：以「面部特征 + 一道独特疤痕 / 饰品」做唯一排他锚点，防变脸。

### 场景资产
- **空间**：大笔触概括远景，焦点落在主体与近景，背景虚化为色块与氛围。
- **材质**：墙面、岩石、地面靠笔触方向模拟粗糙度；金属与水面点高光。
- **光影**：单一主光源 + 强体积感，明暗交界明确，常用顶光 / 侧逆光塑造戏剧性。
- **氛围**：烟尘、体积光、飘落物增强概念叙事感。

### 光影渲染
- 强调「体积感与结构」，亮暗两大块优先，边缘光分离主体。
- 副色（反射光 / 环境色）丰富，色彩厚重，避免平涂。

### 提示词与 MJ 参数
`数字厚涂，油画质感，丰富笔触，写实光影结构，概念艺术风格，深沉色彩，强调体积感，无描边，大师级画作`
推荐：`--ar 3:4` 或 `--ar 16:9`（概念横幅）、`--style raw`、`--stylize 250-400`、`--sref` 锁定画师质感。

## 二、薄涂清新（thin-wash）

### 风格定位
水彩 / 淡彩质感：颜色清透、边缘柔和、大量留白，**治愈系、明亮干净**，情绪轻盈，适合青春、日常、情感向。

### 服装资产
- **形制**：宽松日常、校服、棉麻长裙、针织等柔软款式为主。
- **面料表现**：淡彩晕染表现轻薄——衣褶用浅色叠加过渡，无硬高光；透光感靠留白暗示。
- **配色**：低饱和马卡龙 / 莫兰迪系（藕粉、雾蓝、薄荷、奶黄、米白），色相干净。
- **细节**：极少硬细节，纽扣、褶皱点到为止，强调「空气感」。

### 人物资产
- **骨相**：弱化骨骼，圆润柔和脸形，几乎无明暗硬转折。
- **五官**：细线轻描或色点暗示，眼睛大而清澈，多用高光点。
- **皮肤**：薄透粉调腮红，无毛孔质感，干净通透。
- **锚点**：用发色 / 一件小配饰（发卡、围巾、发绳）作锚点，柔和不突兀。

### 场景资产
- **空间**：留白即空间，背景常淡化为水彩晕块（天空、树影、光斑）。
- **材质**：纸张纹理 / 水痕边缘是核心质感，不追求写实。
- **光影**：漫射柔光，无影或极淡影，常加「透光」「过曝」的明亮感。
- **氛围**：樱花、光斑、微风、云影等轻盈元素。

### 光影渲染
- 光源弥散、明暗对比极低，画面整体偏亮、偏通透。
- 边缘柔化、虚化过渡，追求「会呼吸」的干净。

### 提示词与 MJ 参数
`水彩淡彩，清透色彩，柔和边缘，留白艺术，治愈系氛围，低饱和度，纸张纹理，轻盈线条，明亮干净`
推荐：`--ar 3:4`、`--stylize 150-300`（过高会破坏通透）、`--sref` 锁水彩肌理。

## 三、欧美商业插画（western-commercial）

### 风格定位
欧美游戏原画 / 卡池海报风：**高饱和、强动态、戏剧光**，角色摆夸张姿势，金属与魔法特效华丽，视觉冲击拉满。

### 服装资产
- **形制**：夸张剪影——披风、铠甲、能量武器、 oversized 肩部；强调轮廓可读性。
- **面料表现**：金属 / 能量 / 布料三种质感高对比并置，硬高光 + 锐利反射。
- **配色**：高饱和互补撞色（青橙、紫黄、红绿），主体色跳脱背景。
- **细节**：繁复雕纹、镶嵌宝石、能量纹路，堆料显「史诗 / 稀有度」。

### 人物资产
- **骨相**：英雄化比例（宽肩 / 长腿 / 强结构），姿态有张力（蓄力 / 回眸 / 跃起）。
- **五官**：立体锐利，戏剧性明暗，眼神强烈。
- **皮肤**：写实偏厚涂，受光面与轮廓光分离，常带环境反光色。
- **锚点**：武器或标志性特效（火焰 / 雷电 / 符文）即最强身份锚点。

### 场景资产
- **空间**：服务角色的舞台化背景——崩塌战场、魔法阵、王座厅，透视夸张。
- **材质**：金属、水晶、能量场为主，强反射。
- **光影**：戏剧性主光 + 轮廓光 + 底部反弹光，明暗对比极强，常用逆光剪影起手。
- **氛围**：飞溅火星、漂浮碎石、能量粒子、镜头光晕。

### 光影渲染
- 「为冲击力服务」：光源方向刻意安排以强化姿态，冷暖分区对立，亮部可过曝、暗部可压黑。

### 提示词与 MJ 参数
`欧美游戏原画风格，高饱和色彩，强烈动态姿势，戏剧性光影，精致金属与魔法特效，史诗感，视觉冲击力强`
推荐：`--ar 3:4`（立绘竖版）/ `--ar 16:9`（横幅海报）、`--stylize 400-600`、`--chaos 10-25` 增加姿态变化。

## 四、日系写实插画（jp-real-illust）

### 风格定位
新海诚 / 吉卜力写实向：**背景美术极度细腻、光影追踪真实、丁达尔光效、清新空气感**，情感充沛，背景往往比角色更出彩。

### 服装资产
- **形制**：写实校服、通勤装、生活化穿搭，褶皱物理合理。
- **面料表现**：细腻半厚涂，布料有真实明暗与透光（裙摆、衬衫逆光透光）。
- **配色**：和谐低刺，随场景天色统一（黄昏暖、清晨冷、雨夜青）。
- **细节**：发丝、布料纤维、雨水打湿的边缘都精细刻画。

### 人物资产
- **骨相**：日系美型 + 写实光影结合，脸偏动漫但光照真实。
- **五官**：清澈大眼 + 真实反光（瞳孔映出天空 / 对岸光点），情感写在眼里。
- **皮肤**：通透，逆光边缘有暖色透光辉光（发丝边缘发光）。
- **锚点**：以发型 + 瞳色 + 标志性校服 / 物件锁定，跨镜一致。

### 场景资产
- **空间**：这是核心——城市天际线、铁道、天台、教室、雨后街道，细节拉满、纵深深。
- **材质**：玻璃幕墙反光、湿地倒影、云层体积、电线与云，照片级细腻但带绘画感。
- **光影**：太阳角度驱动一切——丁达尔光、逆光、晨昏蒙影（magic hour）；天空与云是叙事主角。
- **氛围**：飘落花瓣 / 雨丝 / 光尘，空气透视明显，远山偏蓝。

### 光影渲染
- 「真实时间感」：明确到具体时刻的光（清晨5点/黄昏7点），冷暖随天光变化，逆光与透光大量使用。

### 提示词与 MJ 参数
`新海诚／吉卜力风格，极度细腻背景美术，写实光影追踪，丁达尔光效，清新空气感，色彩和谐，情感充沛，高分辨率背景`
推荐：`--ar 16:9`、`--stylize 250-400`、`--style raw` 提真实感、`--sref` 锁天空色调。

## 五、古风插画（guofeng-illust）

### 风格定位
中国传统工笔 / 水墨：线条流畅、色彩淡雅、留白意境，汉服与云雾承载古典韵味，宣纸质感，东方美学。

### 服装资产
- **形制**：汉服形制准确（曲裾 / 直裾 / 齐胸襦裙 / 大袖衫 / 圆领袍），层叠飘逸。
- **面料表现**：工笔重彩以细线勾勒 + 平涂晕染，丝绸以留白与淡彩高光表现，不堆厚涂。
- **配色**：淡雅传统色（月白、青黛、朱砂、赭石、藕荷、藤黄），低对比，多留白。
- **细节**：云纹、卷草、缠枝、团花纹样以工笔细线描绘。

### 人物资产
- **骨相**：清秀含蓄，柳叶眉、丹凤眼、含情的古典审美，身形修长。
- **五官**：以线造型，眉眼以流畅墨线勾勒，淡彩敷面。
- **皮肤**：白描 + 薄染，几无明暗，靠线与淡色显气韵。
- **锚点**：发髻样式 + 一支簪钗 + 眉心花钿，作身份锚点。

### 场景资产
- **空间**：留白即空间——远山淡影、亭台一角、竹林、烟水；讲究「计白当黑」。
- **材质**：宣纸 / 绢本质感、墨色浓淡干湿、飞白笔触是核心肌理。
- **光影**：弱化明暗，以墨分五色（焦浓重淡清）代替光照，意境大于物理光。
- **氛围**：云雾、落英、孤舟、明月、飞雪，诗画合一。

### 光影渲染
- 不用西方明暗法，靠线条疏密与墨色浓淡造层次；重「气韵生动」而非体积。

### 提示词与 MJ 参数
`中国传统工笔或水墨风格，流畅线条，淡雅色彩，留白意境，汉服元素，云雾缭绕，古典韵味，宣纸质感，东方美学`
推荐：`--ar 16:9`（长卷感）/ `--ar 9:16`（立轴）、`--style raw`、`--stylize 150-300`（保东方克制）、`--sref` 锁水墨调。

## 六、奇幻插画（fantasy-illust）

### 风格定位
集换式卡牌（如《万智牌》）插画风：奇幻生物与魔法元素丰富、细节繁复、史诗构图、神秘光影、色彩厚重，构建幻想世界观。

### 服装资产
- **形制**：法师长袍、精灵轻甲、符文战铠、德鲁伊皮甲等奇幻职装，装饰繁复。
- **面料表现**：厚重厚涂，织锦、锁甲、附魔金属分别以块面与高光区分；常带自发光符文。
- **配色**：浓郁史诗色（深紫、祖母绿、鎏金、血锈），魔法色作点睛（奥术蓝、邪能绿）。
- **细节**：符咒、镶嵌、雕纹、能量流动等世界观符号密布。

### 人物资产
- **骨相**：种族化特征（精灵尖耳、兽人獠牙、矮人壮硕），造型夸张有辨识度。
- **五官**：锐利，带魔法 / 符文光效（发光眼、面纹）。
- **皮肤 / 体表**：可有鳞片、符文灼痕、能量脉纹等奇幻质感。
- **锚点**：以法杖 / 契约兽 / 族徽符文做身份锚点。

### 场景资产
- **空间**：史诗奇幻场景——浮空城、巨龙巢穴、古代遗迹、魔法森林，纵深宏大。
- **材质**：岩石、水晶、魔法能量、巨兽甲壳，细节堆叠。
- **光影**：神秘氛围光——魔法自发光源、神光穿云、地穴微光，冷暖对比强。
- **氛围**：漂浮符文、魔法阵、飞灰、雾气，叙事性强（像定格一张「卡牌故事」）。

### 光影渲染
- 「一个魔法光源统摄画面」：主光常来自画面内魔法物（法杖、龙焰、符文），色彩叙事浓烈。

### 提示词与 MJ 参数
`奇幻卡牌风格，丰富奇幻生物与魔法元素，复杂细节，史诗构图，神秘光影，厚重色彩，幻想世界设定`
推荐：`--ar 3:4`（卡牌竖构图）、`--stylize 400-600`、`--chaos 10-20`、`--sref` 锁奇幻调色。

## 七、科幻插画（scifi-illust）

### 风格定位
未来主义概念插画：硬表面机械设计、冷色调、霓虹光效、复杂科技细节，蓝图 / 概念设定图感，常与赛博、太空歌剧结合。

### 服装资产
- **形制**：机能服、太空服、外骨骼、军用装甲，硬表面 + 模块化。
- **面料表现**：硬表面为主——金属、复合板、玻璃面罩，锐利高光与边缘光；柔性织物仅作内衬。
- **配色**：冷色主调（青、钢灰、深蓝）+ 霓虹点缀（青 / 品红 / 琥珀），工业感。
- **细节**：接口、管线、指示灯、编号、装甲接缝等「设定密度」极高。

### 人物资产
- **骨相**：写实 / 半写实，常带义体、植入接口。
- **五官**：冷峻，可有 AR 瞳光、面罩、扫描光条。
- **皮肤 / 材质**：皮肤与金属 / 合成材料交界清晰，义体边缘发光。
- **锚点**：以标志性义体 / 头盔 / 编号涂装锁定。

### 场景资产
- **空间**：轨道站、飞船舱、未来工厂、赛博街区的硬表面空间，结构严谨透视强。
- **材质**：金属拉丝、玻璃、全息投影、湿地反光，工程感。
- **光影**：冷底 + 屏幕 / 霓虹点光源，体积光与全息光条，明暗对比强。
- **氛围**：数据流、全息 HUD、蒸汽、漂浮颗粒。

### 光影渲染
- 「为设定服务」：光用来交代结构（边缘光勾硬表面轮廓），冷暖分区，可加 blueprint 蓝图光效。

### 提示词与 MJ 参数
`未来主义设计，硬表面机械，赛博或太空歌剧风格，冷色调，霓虹光效，复杂科技细节，概念设计图，蓝图感`
推荐：`--ar 16:9`、`--style raw`（保工程严谨）、`--stylize 200-350`、`--sref` 锁冷色调。

## 八、童话插画（fairy-illust）

### 风格定位
儿童绘本风：圆润线条、柔和梦幻色彩、想象力生物、温馨天真、故事感强，常有蜡笔 / 彩铅 / 水粉肌理。

### 服装资产
- **形制**：童话服装——斗篷、背带裤、公主裙、小马甲，造型圆胖可爱。
- **面料表现**：蜡笔 / 彩铅 / 水粉的颗粒质感模拟布料，无硬高光，边缘圆钝。

## 组合心法：题材 × 风格 × 一致性

1. **先定「画什么」**：从题材库选内容美学（古风 / 赛博 / 奇幻 / 都市 / 童话……），决定服装形制、人物种族、场景世界观。
2. **再定「怎么画」**：从本库选一种 CG/插画风格，决定笔触、描边、上色与光影逻辑。同一题材换不同插画风格，成品气质天差地别（如「古风 + 厚涂写实」偏概念设定、「古风 + 水墨工笔」偏传统韵味）。
3. **锁一致性**：跨镜、跨图保持同一风格时，固定 `--sref`（风格参考）锁笔触与配色；锁定同一角色时用 `--cref`（角色参考）+ 面部锚点词。
4. **参数随风格走**：越写实/厚重（厚涂、欧美、奇幻）stylize 可高；越靠留白通透（薄涂、矢量、古风、钢笔淡彩）stylize 越低，以免 AI 过度美化破坏风格纯度。
5. **资产入库建议**：把每种风格的「服装 / 人物 / 场景」三段作为字段模板，喂小说文本给大模型按字段抽取补全，再拼接本库风格关键词与 MJ 参数即可成图。

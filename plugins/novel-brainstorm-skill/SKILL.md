# novel-brainstorm-skill

小说开书头脑风暴：书名候选、立意火花、卖点。不产出枚举 id，不写 patch。

## 用途

围绕开书意图发散火花，供 `novel-writer-skill` 落成表单字段。

下一棒由 `novel-writer-skill` 把火花落成表单字段。

## 执行动作

| action | 说明 |
|--------|------|
| ideate | 按 focus 发散（title / intent / summary / genre / themes / auto） |

## 出参

```json
{
  "thinking": "",
  "reply": "给作者看的火花说明",
  "sparks": ["候选1", "候选2"],
  "suggested_fields": ["title"]
}
```

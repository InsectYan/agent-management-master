# 公共动作知识库

生成提示词的技能整理镜头时，正文或常规稿里出现动作，就读取这里对应的模版，把起始姿态、肢体路径和结束姿态写进提示词。

新增打戏或特效时，在 `packs/` 放一篇说明，再在 `index.js` 的目录里加一条。`group` 用 `fight` 或 `fx`，`gate` 用 `none`。不要改已有亲密模版的使用条件。

## 使用条件

亲密类模版只在这一镜里发生身体接触的人都已写明满二十一岁时调用。没写年龄，或出现未满二十一岁，不调用亲密模版，只保留单人的肢体路径。

打戏和特效没有年龄门槛。这两类现在还没有条目。

男女体征写在 `anatomy.md`。只有 AV 技能会读它，而且要这一镜已经写明双方都满二十一岁，并且命中了上面的亲密动作。常规提示词技能不引用这份体征说明。

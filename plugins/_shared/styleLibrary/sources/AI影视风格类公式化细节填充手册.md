# AI 影视风格类·公式化细节填充手册

> 本册延续整套漫剧/真人剧知识库的「四大公式逐格取数」写法：每个影视风格都不堆砌空泛描述，而是按 **服装 / 人物 / 场景 / 人景融合** 四大公式的字段顺序，逐槽位给出该风格在此字段的取数口径，可直接喂大模型按小说文本逐格召回填充。**本轮按要求已剔除原始清单中缺少完整描述（缺第五个提示词参数）的 5 条：港风怀旧感 `film-hk-nostalgia`、黑色电影风格 `film-noir`、美式青春片风格 `film-us-youth`、印度歌舞片风格 `film-bollywood`、欧洲冷感系 `film-euro-cold`，以下仅保留有完整描述的影视风格。**


## 〇、公式槽位框架

影视风格 = 内容（人/景）× 镜头语言 × 调色分级。所有风格共用同一套四公式骨架，跨风格**只换槽位取值、不换结构**。


| 公式 | 槽位（固定顺序） |
|---|---|
| 服装公式 | 年代/地域身份 → 主服装单品 → 面料材质 → 剪裁廓形 → 颜色纹样 → 做旧与状态 → 配饰唯一锚点 |
| 人物公式 | 脸型气质 → 妆容 → 发型 → 表演状态 → 表情姿态 → 唯一锚点 |
| 场景公式 | 空间类型 → 光源类型与方向 → 色调分级 → 画幅镜头 → 氛围元素 → 颗粒/画质 |
| 人景融合公式 | 光影同源 → 人物在景位置 → 运动/剪辑暗示 → 情绪基调 → MJ参数 |


**影视类三条共性铁律**：


1. **风格词优先于内容词**——先锁定胶片/布光/画幅/年代，再往里填人与景；先定「用什么镜头和调色拍」，再定「拍什么」。
2. **光影与色彩分级是风格命门**——每个风格必须同时锁定「光源类型+方向」与「色调倾向/分级」，二者缺一即失真；黑位、高光、肤色偏色是识别关键。
3. **人物资产先固化再谈分镜**——先出定妆照 + 正侧背三视图锁死五官发型服装，再谈镜头与剪辑，否则跨镜极易换脸换衣。

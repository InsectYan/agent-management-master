# AI 兼容旧项风格「公式化」细节填充手册

> 本册面向项目中的**兼容旧项（legacy 风格映射）**，不重复堆砌风格描述，而是严格套用《视觉资产提示词公式手册》的**四大公式模块顺序**，对每一种**有完整描述**的风格，逐字段给出「该公式的每个槽位，在这种风格下应填什么细节」的取数口径。把小说文本喂给大模型后，按对应风格的对应槽位召回、补全、组装成可执行生图提示词，并保证多集多镜一致。
>
> **口径约定**：凡条目缺少完整第五段描述（即只给了标签、没有具体提示词文本）的，一律**不纳入本册**（如：赛璐璐 cel、黑白漫画 manga-bw、美漫 comic-us、韩漫条漫 webtoon、Q版 chibi、动态漫 motion-comic、线稿 lineart、像素 pixel、剪纸 papercut、低多边形 lowpoly、蒸汽朋克 steampunk、蒸汽波 vaporwave、哥特 gothic 等共 13 条）。其余 34 种有完整描述的旧值已全部收录。
>

## 〇、四大公式槽位框架（取数骨架，全风格通用）

| 公式 | 模块顺序（每个槽位都是一个待填字段） |
| --- | --- |
| 服装 | [颜色] + [材质] + [款式] + [细节设计] + [工艺特征] + [整体风格] + [MJ参数] |
| 人物 | 基础身份 + 面部特征 + 身材体型 + 发型妆容 + 服装细节 + 饰品道具 + 光影氛围 + 镜头构图 + 风格质感 + MJ参数 |
| 场景 | 空间类型 + 建筑结构 + 材质纹理 + 光影氛围 + 叙事道具 + 镜头构图 + 天气时间 + 风格质感 + MJ参数 |
| 人景融合 | [景别构图] + [人物锚点] + [动作落脚点] + [空间前后景] + [光影统一] + [MJ参数] |

> 兼容旧项共性铁律（贯穿所有槽位）：① **先锁媒介/渲染体系，再填内容**——本批横跨赛璐璐 2D、三渲二、写实三维、电影实拍、油画/水墨/工笔/壁画等绘画媒介、扁平矢量与黏土定格，每种风格的第一开关是「用什么媒介/着色方式表达」，媒介词必须先进提示词；② **一致性靠锚点**——2D 动画用 `--niji 6` + `--cref` 锁脸，三维用固定渲染风格与 `--cref`，写实/胶片用颗粒与实拍关键词，媒介类把笔触/纸纹/颜料/墨色写成可复现的关键词；③ **兼容旧值只做「翻译」不做「重写」**——同一内容换风格时，只替换对应媒介槽位的口径（如把「皮肤」从写实的「可见毛孔」换成油画的「明暗堆色」、换成扁平的「纯色块」），结构骨架不变。

## 九、公式化落地心法

1. **先锁媒介再填内容**：每个风格的第一格（服装-颜色 / 人物-面部 / 场景-材质）都要先落定「用什么媒介/着色方式表达」，媒介词（`cel shading`/`toon shader`/`oil painting`/`ink painting`/`gongbi`/`ukiyo-e`/`claymation`/`flat vector`/`35mm film` 等）必须出现在 MJ 参数前部。

2. **把内容翻译成媒介语言**：同一「皮肤」在写实填「可见毛孔/细纹」、在油画填「明暗堆色」、在水彩填「淡彩晕染+留白」、在版画/扁平填「纯色块/灰阶」——跨风格只换槽位值，不换结构骨架。

3. **光影槽是风格开关**：硬边明暗=赛璐璐/三渲二/扁平；柔和漫射=吉卜力/皮克斯/绘本；戏剧侧逆+分级=写实/电影；明暗对照=油画/素描/暗黑；浓淡干湿=水墨/工笔；平面匀光=壁画/浮世绘；体积+法术光=国漫/仙侠/赛博。锁定光影就锁定了 80% 的风格。

4. **人物资产先固化**：无论哪种媒介，都先出该风格的定妆照 + 正侧背三视图锁脸/锁配色/锁造型，再谈分镜；2D 与三维用 `--cref` 跟角色，写实/胶片先锁真实脸形与五官。

5. **人景光影同源**：人景融合公式的「光影统一」格必须与人物/场景公式的光影槽同源同向——动画硬光向统一、写实主光方向一致、水墨浓淡虚实一致、壁画平面光一致，否则会出现「人被合成进背景」的割裂感。

6. **兼容旧值的映射纪律**：本批旧值多数已被前面各册（3D 类 / CG 插画类 / 二次元类 / 写实类 / 经典艺术类 / 影视类）覆盖，本册提供的是「旧 value → 公式槽位」的直接映射；迁移新项目时优先沿用对应新册的更细口径，本册作为兜底与对齐基准。

7. **重复描述条目的区分**：`anime-3d`/`toon-shader`、`realistic`/`cinematic`、`ink`/`ink-wuxia`、`gongbi`/`guofeng`、`picture-book`/`fairy` 等在原库中描述相同，本册按名称语义做了差异化侧重（如半写实偏美颜、三渲二偏 ramp 色阶、武侠水墨偏动势泼墨），实际取用时以项目主题择一即可。
